# mobile ai

> **移动AI** —— 人在路上任意飘，家里电脑爆缸开工。

零安装的隧道服务：一条终端命令，把**家中电脑的任意本地工具/服务**同步到你的手机和任何设备。
无需端口转发、无需公网 IP、手机上不装任何 App——浏览器打开一个 URL 即可。

DeepSeek Harness（DSH）是内置默认用例，但 mobile ai 不关心你跑的是什么——localhost 上的任何服务都可以。

---

## ⚠️ 安全须知（使用前必读）

1. **你的专属 URL = 访问凭证。** 它等价于那台机器的钥匙：泄露给谁，谁就能操作你的本地服务。
2. **暴露什么服务由你负责。** mobile ai 提供通道与身份管理，不审查、不经手、不留存你的流量内容。
3. **建议只暴露你信任的服务**（如 DSH 这类带审批/沙箱机制的工具），并善用一键轮换 URL。
4. 本工具要求目标机器保持开机且网络可达；睡眠/关机期间隧道离线，唤醒后自动重连。

## 工作原理

```
手机浏览器 ──HTTPS──▶ https://<你的随机子域>.newapi.email   (Cloudflare 边缘 + 访问鉴权)
                              │
                    ┌─────────▼────────┐
                    │ 你的电脑（常驻）    │ ← cloudflared 出站连接，无需公网 IP/端口转发
                    ├──────────────────┤
                    │ 任意本地服务        │   默认: DSH @ 127.0.0.1:3080
                    └──────────────────┘
```

- 数据只经过 Cloudflare 边缘加密中转，mobile ai 控制面**不接触你的业务流量**。
- 机器码绑定 + 心跳校验：单终端授权，异地/异机使用自动吊销。

## 快速开始

```sh
# macOS / Linux
curl -fsSL https://newapi.email/i.sh | bash

# Windows (PowerShell)
irm https://newapi.email/i.ps1 | iex
```

脚本会自动拉取所需组件并**弹出浏览器窗口**，全程只需填写两项：

| 字段 | 默认值 |
|---|---|
| 本机服务地址 | `127.0.0.1:3080`（DSH；可改为任意 host:port） |
| 认证码 | （购买后邮件/门户获取，一次性核销并绑定本机） |

点击「启动隧道」→ 页面显示你的专属 URL → **手机浏览器打开即用**。
开机自启、断线重连均已自动配置，之后无需任何操作。

## 特性

- **一条命令 + 一个浏览器页面**：无安装包（不产生 .pkg/.exe），无签名/白名单摩擦
- **任意服务、任意端口**：DSH 只是默认值，任何 localhost 服务皆可
- **机器码 + 单终端绑定**：心跳校验（离线宽限、错机即杀），换机走付费重绑
- **随机子域 = 凭证**：不可猜测 + 一键轮换，旧 URL 秒失效
- **常自动重连**：launchd / systemd user / Windows 计划任务，三平台一套逻辑
- **统一黑白设计**：本地控制台与官网同一套极简视觉系统
